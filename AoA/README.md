# AoA — Angle of Attack

Open **AoA.html** by double-clicking it in Windows File Explorer. It runs locally in your browser; no Python command or internet connection is needed to use the diagram.

Move the slider from **−4° to +8°** to see the airfoil's chord change angle relative to the fixed incoming airflow. The leading edge, trailing edge, chord and angle α are labelled.

This is an educational angle-of-attack visual. The airfoil outline is illustrative; it does not predict lift, drag or stall and is separate from the trained BTP predictor and the 2D/3D generators.

Files:

- `AoA.html`: self-contained local version with embedded styles, diagram and controls.
- `source/angle-of-attack.html`: editable visualization source preserved from the chat.
